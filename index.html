01 — OPERATIONS業務改善

座席と予約を、スマホひとつで。

飲食店向けの座席配置・予約管理アプリ。テーブルをドラッグして配置し、予約名をその場で入力。紙の座席表を書き直す手間を減らします。

課題と制作内容を見る
課題
テーブルの結合や空席の確認のたびに、紙やホワイトボードの書き直しと目視確認が必要でした。
作った仕組み
6卓×4席の配置、近接したテーブルの自動結合、予約名の入力、予約状況の一覧表示に対応。データは端末のブラウザに保存します。
運用上のポイント
単一HTMLで動作。保存先は端末ごとのため、複数端末での予約共有を前提としたシステムではありません。

02 — SALES SUPPORT営業支援

「こんなHPが作れます」を、提案に。

地域事業者向けのWebサイト提案を支える制作フロー。候補事業者の抽出から競合調査、サンプルHPと営業プランの作成までをつなぎます。

課題と制作内容を見る
課題
口頭だけでは、ホームページを持つメリットや完成イメージが伝わりにくい。具体的なサンプルを見せるための準備にも時間がかかっていました。
作った仕組み
市区町村を指定し、ホームページを持たない工務店・塗装業などの候補を抽出。Claudeで競合サイトを調査し、業種に合わせたサンプルと営業プランを生成します。
活用場面
伊豆エリアの事業者への訪問営業の準備に活用。調査とサンプル作成を一つの流れにまとめました。

03 — AI WORKFLOW提案書作成

9つの視点で、提案を組み立てる。

課題分析・施策設計・効果試算・資料制作を、役割を分けたAIで支援。中小事業者向けの業務改善提案を、A4・2ページのPDFにまとめます。

課題と制作内容を見る
課題
分析から価格設定、資料作成までを一人で進めると、検討項目に抜け漏れが生じやすいことが課題でした。
作った仕組み
9つの役割を持つAIエージェントで分担。効果試算と価格の整合性を検討し、施策を個別に選べる提案書を作成します。試算は前提条件に基づくもので、成果の保証ではありません。
活用場面
個人美容師や5名規模の自動車整備工場などに向けた提案書を複数作成し、営業資料として活用しています。

AIエージェント / Python / PDF生成

04 — CONTENT OPS記事運用

書いた記事を、下書きまで運ぶ。

Googleドキュメントの記事を、画像とともにnoteの下書きへ。コピー＆ペーストや画像の貼り直しを減らし、投稿準備を自動化します。

課題と制作内容を見る
課題
記事を投稿するたびに、本文の転記・画像の貼り直し・書式調整が発生していました。
作った仕組み
ドキュメントのURLからHTMLを取得し、記事構造を変換。画像の一時保存とブラウザ操作を経て、noteの下書きを作成します。
活用場面
URLを渡すコマンドで投稿準備を実行。公開前の確認と編集を行えるよう、下書きとして保存します。

Python / Playwright / Google Docs

ケアセンターの経営管理に携わりながら、業務や営業の中で感じた課題を、AIとコードを使って仕組みにしています。

専門知識のないところから、Claude Codeを活用して要件を整理し、ツールを一つずつ制作してきました。飲食店の予約管理から営業資料の作成、記事の投稿準備まで、出発点はいつも「この作業を、もう少しうまく回したい」という思いです。

大切にしているのは、作ったものが実際の仕事に役立つこと。経営管理や営業の合間に、必要になった仕組みを積み重ねています。
